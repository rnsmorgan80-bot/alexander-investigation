# RM Ancient History — Alexander investigation

This is a complete static website intended for **GitHub Pages**. It requires no paid hosting, build pipeline, plugins, database, analytics, images from other websites, or external JavaScript libraries. All activity works offline when `index.html` is opened locally.

## Where it goes

- `index.html`: finished public experience (the welcome page, Babylon mystery, ancient-language witness gallery, historical successor map, counterfactual power game and timeline)
- `.nojekyll`: lets GitHub Pages serve files without Jekyll processing
- `assets/preview.png`: optional promotional image for your WordPress article (generated from the finished webpage)
- `WORDPRESS_ARTICLE.md`: polished historical introduction, easy to copy into the WordPress editor
- `WORDPRESS_ARTICLE.html`: a simple HTML text-only version for a Custom HTML block; **do not add JavaScript or an iframe to WordPress Free**
- `PUBLISHING_GUIDE.md`: step-by-step instructions

## Historical conventions

Contemporary Babylonian diary (BM 45962) is separate from the later references to the lost Royal Journals. The source library deliberately gives versions from Plutarch, Arrian, Diodorus, the Greek Alexander Romance and Quintus Curtius, with source links and English translation. The interactive map is schematic rather than geographically accurate. Power balance numbers are **fictional game values**, not military estimates. A political beneficiary is not automatically a suspect.

## Privacy

No analytics, cookies, form submissions, back-end data collection, embedded audio or other remote scripts. All decisions are processed in the visitor's browser, and no answers are stored. External bibliography links open only when clicked.

## Sharing

Do not insert the GitHub URL into your WordPress button until it is actually live. You will receive the actual public URL after enabling GitHub Pages under Settings > Pages.
